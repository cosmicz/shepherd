#+title: Shepherd — application development
#+date: [2026-10-11 Sun]

This file holds durable architecture notes.

* Architecture
The domain defines assessments, closed reason and pattern codes, generic event
summaries, route traces and explicit uncertainty. The application layer owns
capture consent, generation-based cancellation and bounded sampling. Adapters
supply browser capture, local OCR, the native helper's text frames, the local
model, the cloud judge, local speech, the family alert and browser-local
summary storage. A Node service binds to loopback and serves the companion,
the analysis endpoint, the consent registry and the judge trace page.

Routing is a pure policy over rules, local model and cloud judge outcomes with
a total decision table; every tier records a trace step with duration,
remote calls, bytes sent and cost. Cloud dispatch requires a grant bound to
session, generation and source, validated immediately before the call.
Speech and family text come from fixed templates keyed by closed codes.

The cloud-judge provider identity is ~openrouter~ and retains the resolved
upstream model identifier. Schema parsing accepts historic ~anthropic~ labels
only for previously persisted payload compatibility; new assessments emit
~openrouter~. Cloud evidence is redacted before serialization: an unattempted
request records zero remote calls and zero bytes, while a dispatched request
records its exact serialized UTF-8 byte count.

The trace intentionally includes bounded OCR text, app/window/URL context,
evidence, messages and model-produced summaries. It remains local behind the
loopback/token boundary. Browser history is a separate opt-in store of at most
100 generic summaries. The journal collector is wired through injected ports
and remains off until the companion's local recording switch is enabled. It
retains periodic and suspicious observations, with a separate token-authorized
inspector read endpoint and explicit delete-all. The default directory is
app-private; any configured directory must be dedicated to this journal.
Models currently analyze individual observations, not a sliding history.

Journal tests use synthetic observations. Available text is preserved, but the
browser PNG collector does not promise complete OCR for every observation.
Retention has no automatic expiry; the UI explicitly warns that it accumulates.

The default cloud judge uses OpenRouter Decisions with Clef Flash. Clef and Jev
are configurable alternatives; the chat-completion adapter can instead use
Opus. Only one cloud judge is selected. Decision distributions are display-only,
uncalibrated values, not routing thresholds. Rules annotate by default; the
legacy support-pressure shortcut is an explicit opt-in. Offline feed matches
decorate trace rows and do not change policy decisions.

Local-model lifecycle is managed through a loopback llama-server process port.
Existing external servers are reused without taking process ownership. Native
accessibility observation is opt-in; voice source adapters are independent of
browser capture. No test should request an operating-system permission.

[2026-10-11 Sun] Native-eyes source normalizes the Swift helper's JSONL into
~TextFrame~ values through an injected process boundary. It never shortens a
URL: oversized addresses become null with ~url_status: too_long~. Text is kept
only through a complete UTF-8 line within 32 KiB and marked ~truncated~, so a
clean partial reading remains inconclusive. The real helper remains
operator-run from Terminal.app; tests use a fake child process only.

[2026-10-11 Sun] The helper executable defaults to the documented repository
build location and may be overridden by ~SHEPHERD_EYES_BIN~. Spawn errors,
typed helper stderr and unexpected exits map to fixed local unavailable states;
raw process diagnostics do not enter the companion or trace. Captured text can
appear in the local evidence view under the bounds described above.


* Validation
The public snapshot uses fixed code with a version-bound eight-fixture receipt.
Public documentation and test labels omit private workflow identifiers; receipt
provenance explicitly marks redacted source identifiers. Historical measured
receipts retain their original policy/model binding. Partial local-model input remains inconclusive
when its otherwise-final result would be no_signal.

~npm run check~ runs the native tests, the tools suites, the TypeScript build
and the Chromium boundary test. Real OS permissions, local-voice behaviour and
live model calls are witnessed manually.
