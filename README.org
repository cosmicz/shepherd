#+title: Shepherd — local screen companion
#+date: [2026-10-11 Sun]

Shepherd watches a screen surface you choose, looks for scam pressure, and
offers a plain-language caution. It combines local OCR and rules, a local
language model, and an optional cloud judge. This is a hackathon prototype:
it can miss threats or flag innocent content. No result authenticates a person,
website or message.

* Run the companion
Use Node 22.12 or newer, npm, and Tesseract with English language data.
Playwright Chromium is needed for browser tests.

#+begin_src sh
npm ci
tesseract --version
tesseract --list-langs
npx playwright install chromium
npm run check
npm start
#+end_src

Open ~http://127.0.0.1:4317/companion~ in Chrome. Start opens the browser's
screen-sharing picker; the app analyzes the surface you select every five
seconds, after the preceding analysis completes. Choose a window or tab for
the demo. The browser may also offer a whole display; that includes everything
visible on that display. Pause stops capture and revokes the cloud grant.
Read aloud uses the browser's speech service; offline voice availability is
not guaranteed.

~npm run dev~ builds and starts the service; it is not a file watcher.
~SHEPHERD_PORT~ changes the default port. Only ~127.0.0.1~ is bound; use that
address because the Host check is exact. ~/trace~ shows content-free route
events, cloud-call counters and reported costs. The root URL returns status.

The tests use synthetic screenshots, fake transports and a fake browser picker.
They do not establish real operating-system capture or Messages permissions.

* Models and optional family alerts
The local tier expects llama-server on ~http://127.0.0.1:8080~. With existing
Qwen3 8B GGUF weights, start it separately:

#+begin_src sh
llama-server -m /path/to/qwen3-8b-q4_k_m.gguf --host 127.0.0.1 --port 8080 -c 8192 --jinja
#+end_src

~SHEPHERD_LLAMA_URL~ selects another loopback port. The adapter uses
non-thinking, schema-constrained output. Risk labels are not calibrated
probabilities. Without the service, the runtime reports the missing tier;
narrow rules still operate.

The cloud adapter uses OpenRouter. Put ~OPENROUTER_API_KEY~ in an untracked
local ~.env~ file, then run:

#+begin_src sh
node --env-file=.env dist/server/main.js
#+end_src

~SHEPHERD_CLOUD_MODEL~ overrides the configured model identifier. A key alone
does not enable dispatch: the companion must register an explicit, unexpired
grant for the current session generation and source. A new grant supersedes
every earlier grant. Pause or source change requires consent again.

~SHEPHERD_FAMILY_HANDLE~ optionally enables fixed-text Messages alerts.
~SHEPHERD_PERSON~ and ~SHEPHERD_FAMILY_NAME~ set local names. The demo persona
enables speech, summary history and family preferences, but never cloud
consent; without a configured family handle, delivery is unavailable.
Messages availability and recipient reachability require manual verification.

* Capture and data boundaries
The browser capture path sends the chosen image to the loopback service for
Tesseract OCR. A separate macOS helper is documented in
[[file:tools/shepherd-eyes/README.org][the native helper guide]]. It uses Vision OCR and defaults to the whole
primary display, including adjacent windows from other apps. Its
~--include-app~ option gates on the frontmost app; it does not hide other
apps' pixels. ~--scope window~ limits that helper to the frontmost window.
The helper is not automatically started by the companion in this snapshot.

Pixels and OCR text are transient in the application. Optional browser history
keeps at most 100 generic summaries, not screenshots, OCR, evidence, titles or
URLs. Full local evidence journaling and automatic expiry are not implemented.

Cloud requests use bounded excerpts and pattern redaction, never screenshots.
By default, only rule-matched spans can form an excerpt; neighbouring lines,
titles and tab bars are not added. Model-quote excerpts are off by default.
~SHEPHERD_QUOTE_EXCERPTS=1~ enables a pressure-cue-gated quote path and changes
the consent statement. A matched span or valid quote can still contain private
text: redaction is not a privacy guarantee. Use synthetic or non-sensitive
pages for the demo. On-screen content and model output are untrusted.

* Interfaces and checks
| Interface | Purpose |
|-----------+---------|
| GET /companion | Capture, explanation and consent controls |
| GET /api/session | Same-origin process token |
| GET /api/capabilities | Configured analyzer capabilities |
| POST /api/analyze | Token/origin-checked PNG or native text frame |
| POST /api/consent | Register one current cloud grant |
| DELETE /api/consent/<id> | Revoke grant and pending associated work |
| GET /trace | Content-free routing display |

~npm run check~ runs root tests, tool suites, TypeScript checks/build and
Chromium specs. ~node demo/check.mjs~ checks the eight synthetic fixtures with
real Tesseract OCR. No paid inference or live screen capture is needed.
See [[file:demo/runbook.org][the demo runbook]], [[file:demo/README.org][the demo kit]] and [[file:eval/README.org][the evaluation guide]].

PNG input is limited to 8 MiB decoded, 5120 pixels per side and 10 million
pixels total. The request-body limit accounts for base64 expansion.
Native text input is limited to 32 KiB. One analysis runs at a time.
Cloud usage has session limits and a bounded cache; unknown cost remains
unknown rather than being reported as free.

* Measured demo and replay
One eight-fixture run found all configured concerns with no false alarms under
the routed policy: one cloud call, 1,498 outbound bytes and USD 0.009 reported
cost. The cloud-only comparison made eight calls (17,327 bytes, USD 0.05989).
The local-only comparison missed one concern. These are small-sample results,
not production accuracy or cost guarantees; OCR time is excluded from latency.
The [[file:eval/README.org][evaluation guide]] contains the receipt, method and limitations.

~SHEPHERD_CLOUD_RECORD~ saves closed verdict codes keyed by excerpt hash, not
screen text. ~SHEPHERD_CLOUD_REPLAY~ loads a rehearsal recording. Replays are
marked REPLAYED, counted separately, and report zero remote calls, bytes and
cost. Missing replay entries are unavailable, never fabricated verdicts.

* Known limitations in this snapshot
- The local model sees at most 4,096 characters. A low result on partial input
  becomes inconclusive, not no_signal. Larger context windows need latency
  evaluation; the fallback does not analyze the omitted text.
- Lookalike-domain heuristics can overflag benign names and miss others.
  ~other_concern~ allows a grounded model concern outside the named categories;
  it does not guarantee novel-attack detection. Only the narrow support-pressure
  rule settles a concern without model confirmation.
- Family delivery failures are surfaced, but an accepted send is not proof
  that the recipient saw the message. Grant expiry and renewal controls are basic.
- Tesseract can interleave multi-column text. Accessibility-tree extraction,
  generated-media detection and local evidence journaling are not included.
- The native-source adapter is tested but not connected to the companion's
  default capture path. Start llama-server separately; managed model lifecycle
  and offline threat-list tagging are not part of this snapshot.
- Fixture measurements are small, historical samples, not guarantees of
  accuracy, privacy, availability or production economics.
