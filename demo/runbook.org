#+title: Shepherd — demo runbook
#+date: [2026-10-11 Sun]

Run these commands from the repository root in Terminal.app. macOS capture
and Messages permissions must be verified in the actual presenting app.
Script: [[file:script.org][script.org]]. Measured results: [[file:../eval/README.org][eval/README.org]].

* 0. Before rehearsal
Run ~npm run check~ and ~node demo/check.mjs~. Install the prerequisites listed
in [[file:../README.org][README.org]]. Keep the OpenRouter key in an untracked ~.env~ file.
Verify Chrome's Screen Recording permission and Messages sign-in manually.
No automated test establishes permission or family-message delivery.

* 1. Terminal tab A — local model
Start the existing GGUF with loopback access only:
#+begin_src sh
llama-server -m /path/to/qwen3-8b-q4_k_m.gguf --host 127.0.0.1 --port 8080 -c 8192 --jinja
#+end_src
Check ~curl -s http://127.0.0.1:8080/health~ for ~{"status":"ok"}~.
Rehearse one analysis before the presentation; startup and cold inference can
take longer. Shepherd does not start this server for you in this snapshot.

* 2. Terminal tab B — runtime
#+begin_src sh
SHEPHERD_FAMILY_HANDLE='<phone or Apple ID that receives the alert>' \
SHEPHERD_PERSON=June SHEPHERD_FAMILY_NAME=Danny \
SHEPHERD_CLOUD_RECORD=demo/cloud-replay.json \
node --env-file=.env dist/server/main.js
#+end_src
Open ~http://127.0.0.1:4317/companion~ and ~/trace~. Check the startup banner:
rules on, local model configured, cloud configured, quote excerpts off.
Leave ~SHEPHERD_QUOTE_EXCERPTS~ unset: by default only rule-matched spans can
leave the machine. Recording saves closed verdict codes keyed by excerpt hash,
not screenshot or model text.

* 3. Terminal tab C — synthetic pages
#+begin_src sh
node demo/serve.mjs
#+end_src
In one Chrome window, open these ~http://<host>:8099/~ tabs:
~weather.localhost~, ~news.localhost~, ~mail.localhost~ (Mars),
~inbox.localhost~ (bank), ~security-alert.localhost~,
~seniorcenter.localhost~, ~messages.localhost~ and ~consumer.localhost~.
Keep companion and trace in other windows.

* 4. Before the clock
1. Start watching and pick the synthetic-pages browser window, including its
   address bar. Do not share private content.
2. Grant cloud consent in the companion. Read its scope statement aloud.
   A new session or source needs a new grant.
3. Check weather: no warning signs found; trace shows local tiers and zero
   remote bytes. Clear or account for rehearsal counters before presenting.
4. Check speech and a real family test message. Do not promise delivery unless
   witnessed on the receiving device.

* 5. Walk the pages
These are observed outcomes in the final eight-page run, not guarantees.
| Page | Observed routed result |
|------+------------------------|
| weather, news | no_signal, local model, row 12c |
| mail (Mars) | concern, local model high plus weak rule, row 7 |
| inbox (bank) | rules/model disagreement; cloud scam verdict, row 13 |
| security-alert | concern from rules alone, row 3 |
| seniorcenter | no_signal, row 12c |
| messages | concern, row 7 |
| consumer | no_signal, row 12c; an earlier run was inconclusive |

The bank example is the cloud beat: weak credential-pressure and AI-instruction
signals survive even when the local model rates the page low. In the final run,
the redacted request was 1,498 bytes, cost USD 0.009, and took 6.9 seconds through
routing, excluding OCR. Narrate over the trace while it runs. The complete
eight-page routed run made one cloud call; cloud-only made eight (17,327 bytes,
USD 0.05989). Use the actual live trace if its outcome differs.

* 6. Replay fallback
If OpenRouter is unreachable, stop tab B and restart:
#+begin_src sh
SHEPHERD_CLOUD_REPLAY=demo/cloud-replay.json \
SHEPHERD_FAMILY_HANDLE='<same handle>' \
SHEPHERD_PERSON=June SHEPHERD_FAMILY_NAME=Danny \
node dist/server/main.js
#+end_src
Start capture and consent again. Say explicitly: “This is the verdict recorded
in rehearsal, replayed locally.” Trace marks REPLAYED with a separate counter
and zero remote calls, bytes and cost. A missing entry is unavailable.
A recording made from fixtures may not match a live screenshot's excerpt hash.

Without a key or replay, cloud is off. Uncertain cases remain inconclusive;
do not present a recorded verdict as live.

* 7. Other fallbacks
- Local server unavailable: trace shows a failed local tier. The narrow support
  popup rule still works; other uncertain cases are inconclusive.
- Capture permission failure: show the synthetic PNGs as labelled examples.
- Family alert failure: the companion surfaces the failure. Check the configured
  handle, Messages permissions and recipient device; never claim unwitnessed delivery.
- Speech unavailable: use the on-screen fixed explanation.

* 8. After the demo
Pause capture, revoke the grant and stop all three terminal processes.
Review recordings before retaining or publishing them; never commit credentials
or private captures.
